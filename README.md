# QRKot — Благотворительный фонд поддержки котиков

## О проекте

**QRKot** — REST API сервис для благотворительного фонда, который собирает
пожертвования и распределяет их по целевым проектам. Фонд помогает котикам:
содержит приюты, оплачивает лечение, корм и другие нужды пушистых подопечных.

### Что умеет сервис

- **Регистрировать пользователей** и аутентифицировать их по JWT.
- **Принимать пожертвования** — зарегистрированный пользователь может внести
  сумму с опциональным комментарием.
- **Управлять целевыми проектами** — суперпользователь создаёт, редактирует
  и удаляет проекты с требуемой суммой.
- **Автоматически распределять средства** — как только появляется новое
  пожертвование или новый проект, свободные суммы автоматически
  инвестируются по назначению.

### Как работает автоматическое инвестирование

- При создании **проекта** — все свободные суммы пожертвований направляются
  в него (в порядке `create_date`).
- При создании **пожертвования** — его сумма распределяется по открытым
  проектам (в порядке `create_date`).
- Как только проект набирает нужную сумму, он закрывается
  (`fully_invested = True`, проставляется `close_date`).
- Как только пожертвование полностью распределено, оно тоже закрывается.
- Все изменения выполняются **в рамках одной транзакции** — состояние БД
  всегда консистентно.

## Стек технологий

- **Python 3.10+**
- **FastAPI** — веб-фреймворк
- **FastAPI Users** — аутентификация и авторизация (JWT)
- **SQLAlchemy 2.0** (async) — ORM
- **Alembic** — миграции
- **Pydantic v2** + **pydantic-settings** — валидация и настройки
- **SQLite** (aiosqlite) — база данных по умолчанию
- **Uvicorn** — ASGI-сервер

## Быстрый старт

### 1. Виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Переменные окружения

Создайте файл `.env` в корне проекта (пример — ниже).

### 4. Миграции

```bash
alembic upgrade head
```

### 5. Создание суперпользователя

```bash
python setup_for_postman.py
```

Скрипт создаст суперпользователя с учётными данными:

- **email:** `root@admin.ru`
- **password:** `root`

### 6. Запуск

```bash
uvicorn app.main:app --reload
```

- Приложение: <http://127.0.0.1:8000>
- Swagger: <http://127.0.0.1:8000/docs>
- ReDoc: <http://127.0.0.1:8000/redoc>

## API

### Аутентификация (`/auth`)

| Метод | Эндпоинт            | Описание                          |
| ----- | ------------------- | --------------------------------- |
| POST  | `/auth/register`    | Регистрация нового пользователя   |
| POST  | `/auth/jwt/login`   | Получение JWT-токена              |
| POST  | `/auth/jwt/logout`  | Выход из системы                  |

### Пользователи (`/users`)

| Метод | Эндпоинт         | Доступ            | Описание                       |
| ----- | ---------------- | ----------------- | ------------------------------ |
| GET   | `/users/me`      | Авторизованные    | Профиль текущего пользователя  |
| PATCH | `/users/me`      | Авторизованные    | Редактирование своего профиля  |
| GET   | `/users/{id}`    | Суперпользователь | Профиль пользователя по id     |
| PATCH | `/users/{id}`    | Суперпользователь | Редактирование пользователя    |

### Целевые проекты (`/charity_project`)

| Метод  | Эндпоинт                  | Доступ            | Описание             |
| ------ | ------------------------- | ----------------- | -------------------- |
| GET    | `/charity_project/`       | Все               | Список всех проектов |
| POST   | `/charity_project/`       | Суперпользователь | Создать проект       |
| PATCH  | `/charity_project/{id}`   | Суперпользователь | Редактировать проект |
| DELETE | `/charity_project/{id}`   | Суперпользователь | Удалить проект       |

### Пожертвования (`/donation`)

| Метод | Эндпоинт         | Доступ            | Описание                   |
| ----- | ---------------- | ----------------- | -------------------------- |
| GET   | `/donation/`     | Суперпользователь | Список всех пожертвований  |
| GET   | `/donation/my`   | Авторизованные    | Список своих пожертвований |
| POST  | `/donation/`     | Авторизованные    | Создать пожертвование      |

## Бизнес-правила

### Проекты

- Название уникально, длина от 5 до 100 символов.
- Описание обязательно, не менее 10 символов.
- Требуемая сумма — целое положительное число.
- Нельзя редактировать закрытый проект.
- Нельзя установить `full_amount` меньше уже вложенной суммы.
- Нельзя удалить проект, в который уже были внесены средства.

### Пожертвования

- Сумма — целое положительное число.
- Комментарий — опциональное поле.
- Пожертвования не редактируются и не удаляются через API.
